# 이미지 자리

직접 만든 그림을 넣는 폴더입니다. 파일이 없으면 게임은 기본 가면 문양을 씁니다. 코드는 그림을 담고 있지 않고, 이 폴더의 파일을 불러오기만 합니다.

| 폴더 | 쓰이는 곳 | 권장 |
|---|---|---|
| `masks/` | 파티 편성 — 출발 준비 초상 · 탑승 멤버 칸 · (도트가 없을 때) 명단 칸 | 가로 18~40px 정도 |
| `sprites/` | 명단 칸 · 탐사 파티 칸(말할 때 통통, HP 낮으면 흔들림, 쓰러지면 회색, 지침이면 꾸벅) · 쉬는 시간·의견 충돌 사건 · 결과 화면 르블랑 · 도감 소원 | 세로 28~44px 정도 |

- 파일 이름은 캐릭터 아이디: `joker` `mona` `ryuji` `ann` `yusuke` `makoto` `futaba` `haru` `akechi` `kasumi` + `.png`
- 투명 배경 PNG, **원래 픽셀 크기 그대로** 저장해 주세요 (게임이 정수 배로만 키워서 픽셀이 뭉개지지 않음)
- 일부만 넣어도 됩니다. 없는 캐릭터는 기본 문양으로 나옵니다.
- 다른 사람이 만든 그림은 작가의 허락을 받은 경우에만 넣어 주세요.
