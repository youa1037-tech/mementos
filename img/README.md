# 이미지 자리

직접 만든 그림을 넣는 폴더입니다. 파일이 없으면 게임은 기본 가면 문양을 씁니다. 코드는 그림을 담고 있지 않고, 이 폴더의 파일을 불러오기만 합니다.

| 폴더 | 쓰이는 곳 | 권장 |
|---|---|---|
| `masks/` | 파티 편성 — 출발 준비 초상 · 탑승 멤버 칸 · (도트가 없을 때) 명단 칸 | 가로 18~40px 정도 |
| `sprites/` | 명단 칸 · 탐사 파티 칸(말할 때 통통, HP 낮으면 흔들림, 쓰러지면 회색, 지침이면 꾸벅) · 쉬는 시간·의견 충돌 사건 · 결과 화면 르블랑 · 도감 소원 | 세로 28~44px 정도 |

- 파일 이름은 캐릭터 아이디: `joker` `mona` `ryuji` `ann` `yusuke` `makoto` `futaba` `haru` `akechi` `kasumi` + `.png`
- 투명 배경 PNG, **원래 픽셀 크기 그대로** 저장해 주세요 (게임이 정수 배로만 키워서 픽셀이 뭉개지지 않음)
- 일부만 넣어도 됩니다. 없는 캐릭터는 기본 문양으로 나옵니다.
- 다른 사람이 만든 그림은 작가의 허락을 받은 경우에만 넣어 주세요.

- `sprites/`는 **2배 디테일(@2x)** 로 저장합니다. 게임은 가로·세로 절반 크기를 기준으로 그려서, 폰 화면(픽셀 밀도 2배)에서 얼굴 같은 잔 디테일이 그대로 보입니다.

## 다락방 배경 (img/bg/)

| 파일 | 쓰임 |
|:--|:--|
| `img/bg/attic.png` | **직접 넣는 배경.** 있으면 다락방 화면이 이 그림을 씁니다. 가로로 긴 그림이면 화면에서 좌우로 밀어서 둘러봅니다 |
| `img/bg/attic-default.png` | 기본 배경(180×136 오리지널 도트, 원근 없는 정면 단면). `attic.png`가 없을 때 씁니다. 화면에는 정수 배율로 커집니다 |
| `img/props/*.png` | 상점 소품 도트(배경과 같은 픽셀 크기, 투명 PNG). 놓이는 자리는 `HUB_SPOTS.def.px`(그림 좌표 x, y, 폭, 높이) |

그림 속 사물을 누르는 자리와 캐릭터가 서는 자리는 `index.html`의 `HUB_SPOTS.custom`에 **그림 크기에 대한 %**로 적혀 있습니다.
- `desk` 지난 판 보고 · `codex` 도감 · `shop` 상점 · `window` 오늘의 메멘토스 · `tv` 타이틀·설정 → `[x, y, 너비, 높이]`
- `stand` 캐릭터 발 위치 `[x, y]` 다섯 곳 (지난 판 3명 + 그날 다락방에 있는 2명)
- `props` 상점 소품이 놓이는 자리 `[x, y]` (안 산 소품은 점선 + 칸으로 보이고, 누르면 상점)

지금 숫자는 가로 약 1.65 : 1 그림(작업대 가운데, 창문 오른쪽 위, 침대·책장·철제 선반 오른쪽)에 맞춰 두었습니다. 다른 그림을 넣으면 이 숫자만 고치면 됩니다.
