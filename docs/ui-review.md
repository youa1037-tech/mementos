# UI 점검 기록 · 2026-11-23

[anything-frontend-art-direction](https://github.com/RNA4219/anything-frontend-art-direction) 스킬(MIT)의 절차로 점검했습니다. 전체 미적 방향(예고장 콜라주, `DESIGN.md`)은 이미 정해져 있으므로, 방향 비교 대신 **같은 내용으로 고친 부분만 전후 비교**했습니다(스킬의 '국소 수정' 기준).

- 주역: 탐사 화면의 캐릭터 말풍선과 로그(캐릭터끼리 벌어지는 일)
- 사용자의 판단: 다음 구역으로 갈지 귀환할지, 사건 선택지
- 확인 방법: 헤드리스 크롬, 390px(휴대폰)·1280px, 같은 난수 시드로 전후 동일 내용
- 미확인: 이 환경에서는 Google Fonts를 받지 못해 **실제 글꼴 렌더링은 확인 못 함**(대체 글꼴로 봄). 실제 기기 터치·스크린리더도 미확인

## 고친 것

| 대상 | 바꾼 것 | 전후로 확인한 것 |
|---|---|---|
| 한국어 줄바꿈 | `word-break: keep-all` + `overflow-wrap: anywhere` | 말풍선·선택지 설명·로그에서 "주제/에", "추/리"처럼 단어 중간에서 끊기던 줄이 단어 단위로 끊김 |
| 말풍선 | 최대 2줄 → 3줄 | 390px에서 류지 대사 "야, 고양이 주제에 무슨 소리냐!"가 잘리지 않고 다 보임. 더 긴 대사는 여전히 말줄임(전체는 로그) |
| 로그 시각 열 (600px 이하) | 가짜 시계(03:32 등) 열 숨김 | 휴대폰에서 로그 본문 폭이 약 22% 넓어짐. 넓은 화면은 그대로 |
| 사건 선택지 들여쓰기 (600px 이하) | 단계마다 16px → 6px | B·C 설명이 덜 꺾임. 사선 계단 느낌은 남김 |
| 작은 빨간 글자 | `#e5191c` → `#ff5a5a` (턴 줄, 사건 도입 강조, 낮은 HP 숫자) | 패널 배경 대비 3.87:1 → 5.92:1 (본문 크기 기준 4.5:1 충족). 큰 제목·면·버튼의 빨강은 그대로 |
| 키보드 포커스 | 1.2초마다 다시 그릴 때 포커스를 같은 버튼으로 되돌림 | 이전: 진행 중 다음 틱에 포커스가 body로 사라짐 / 이후: 버튼에 남음 |
| 넓은 화면 말풍선 | 13px → 14px | 1280px에서 읽기 쉬워짐, 배치 변화 없음 |
| 콜라주 제목 | 단어 사이에 줄바꿈 기회(`<wbr>`) | 긴 제목 대비용. 아래 '정정' 참고 |

## 정정한 관찰

- **사건 제목이 넘친다**고 처음에 봤지만, 글자가 붙는 애니메이션 도중의 화면이었음. 애니메이션이 끝난 상태에선 390px에서 TREASURE CHEST·WARM COFFEE MACHINE 모두 화면 안(가장 오른쪽 글자 366px).
- 리뷰 때 적었던 **파티 화면 가로 넘침**도 같은 이유(화면 전환 애니메이션 도중 측정)였음.

## 남긴 것

- 넓은 화면 탐사 화면은 지도 칸과 아래쪽에 빈 공간이 큼. 배치를 바꾸는 일이라 이번 범위에서 뺌
- 로그 전체에 `aria-live`가 걸려 있어 다시 그릴 때마다 스크린리더가 많이 읽을 수 있음(미확인). 로그를 덧붙이기 방식으로 바꿀 때 함께 처리
- 실제 글꼴(Black Han Sans, Anton 등) 적용 상태에서 같은 비교를 다시 해야 함
