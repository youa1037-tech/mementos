# 아트 바이블 · 다락방 도트

open-game-art-skills의 `art-bible` 규칙 중 **palette-lock** 열을 씁니다. 새 소품도 아래 규칙을 지켜야 같은 방에 놓였을 때 어색하지 않습니다.

## 고정 규칙

| 항목 | 규칙 |
|---|---|
| 타일 | 16×16px. 방은 11×8칸(176×128px), 위 3칸은 벽, 아래 5칸은 바닥 |
| 시점 | 정면 3/4. 소품은 바닥 칸의 아랫변에 발을 붙임. 회전 대신 좌우 뒤집기만 씀 |
| 팔레트 | 아래 25색만 씀(`ART.PAL`). 새 색이 필요하면 이 표를 먼저 고치고 버전을 올림 |
| 외곽선 | 가구·장식은 잉크색(#141012) 1px 외곽선. 러그와 다트판처럼 바닥·벽에 붙는 평면 소품은 외곽선 없이 테두리 색으로 |
| 빛 | 왼쪽 위에서. 윗면과 왼쪽 면에 밝은 단계, 아래쪽에 어두운 단계 |
| 음영 | 재질마다 3단계까지(어둠·중간·밝음) + 하이라이트 1점 |
| 그림자 | 바닥 가구 밑에만, 잉크색 45% 타원. 팔레트 밖 색을 만드는 유일한 예외 |
| 확대 | 화면에서는 정수배(1~5배)로만 키움, 픽셀 보간 끔 |
| 캐릭터 | 넣지 않음. 원작 캐릭터·로고·원작 공간을 그대로 옮기지 않음 |

## 새 소품을 추가할 때

1. `docs/art/manifest.md`에 한 줄 먼저 추가(ID, 레이어, 칸, 크기, 상태)
2. `index.html`의 `SPR`에 그리는 함수 추가. 팔레트 이름(`C.xx`)으로만 칠함
3. `FURN`에 레이어·칸 수 추가, 기본 자리는 `HOME`에
4. `python3 tools/build_atlas.py`로 `docs/art/atlas.png`를 다시 만들어 확인
