# TODAY'S MEMENTOS! · 오늘도 메멘토스!

《페르소나 5 더 로열》 괴도단 10인 중 3명을 골라 메멘토스에 보내고, 그들이 알아서 벌이는 소동을 구경하는 웹 브라우저용 캐주얼 관찰 게임입니다.

- 7턴 탐사: 구역을 고르면 괴도단이 유형(BREAKER · ANALYST · SUPPORT · WILDCARD)에 따라 스스로 행동하고, 중요한 순간에만 선택지가 뜹니다.
- 상태 태그 연계: 앞에서 생긴 [태그]가 이후 사건과 르블랑 후일담을 바꿉니다.
- 메타 루프: 벌어 온 엔으로 르블랑 소품·모나 버스 튜닝·잠입 도구에 투자해 새 대화와 깊은 구역을 엽니다.
- 위험도(RISK): 깊은 구역에 머물수록 위험이 쌓이고, 언제 귀환할지 직접 판단합니다.
- 120가지 파티 조합과 조합 특수 이벤트, 숨겨진 역. 진행도는 도감(CODEX)에서 확인합니다.

## 플레이

`index.html` 하나로 동작하는 정적 페이지입니다. GitHub Pages로 공개하거나 파일을 브라우저로 열면 바로 플레이할 수 있습니다. 진행도는 브라우저의 LocalStorage에만 저장됩니다.

## 파일

- `index.html` — 게임 전체 (HTML · CSS · JS 한 파일)
- `DESIGN.md` — 색·글꼴·컴포넌트·모션 규칙을 정리한 디자인 시스템 문서
- `docs/balance.md` — 위험도·선택지 밸런스 정책과 시뮬 전후 비교
- `tools/sim.py` — 밸런스 시뮬레이터 (개발용, Playwright 필요)

## 안내

비상업 · 비공식 팬 게임입니다. 《페르소나 5》 및 등장인물의 권리는 ATLUS / SEGA에 있으며, 공식 게임의 일러스트·음악·UI 리소스는 사용하지 않았습니다.
